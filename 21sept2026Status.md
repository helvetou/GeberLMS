## What is done

### Process & specifications

- CMMI L3 specs: requirements (`01-exigences.md`), architecture (`02-architecture.md`),
  process/TDD/risks/traceability (`03-processus-cmmi3.md`).
- TDD methodology (red → green → refactor) + strict typecheck.

### Technical foundation

- Strict TypeScript, Vitest, npm scripts (`test`, `test:watch`, `typecheck`).
- **41 green tests**, clean typecheck.

### Business logic (pure, tested domain)

- `vat.ts` — EU VAT rates, "outside EU = 0%" rule.
- `coupon.ts` — % / amount coupons, full free access (100%), expiry, use cap.
- `pricing.ts` — final price: discount on the net, then VAT at the buyer's country (OSS).
- `roles.ts` — roles (`admin`, `learner`, `tutor`) and permissions.
- `user.ts` — `self_payer` flag.
- `guardianship.ts` — tutor ↔ learner link + visibility control (FR-07).

### Decisions made

- **Stack**: SvelteKit + Cloudflare (D1, R2, Workers AI), strict TypeScript.
- **Payment**: Payoneer (Helveticore account already validated) + Revolut withdrawal — **not Stripe**.
- **VAT**: buyer's country rate (OSS scheme), invoice generated by the system.
- **Accounts**: learners created by the admin after payment (no self-signup).
- **LLM budget**: ≤ €100/month.
