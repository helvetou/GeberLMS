# Geber Roadmap — new projects & training to prepare

This folder is **shared between the job-market drone and GeberLMS (LMS
Helveticore)**. It contains *proposals*, not finished material: the new
projects to build and the training to prepare, so the gaps found by the job
scan get closed with concrete, portfolio-visible work.

Status: **planning only.** Nothing here is implemented yet.

## What's in here

- `new-projects.md` — proposed projects (hardware/FPGA + software/Geber
  ecosystem), each tied to a skill gap and to your existing projects.
- `training-to-prepare.md` — the training/course roadmap to prepare, starting
  with Verilog + VHDL (the "no skills today" gap) and then the software gaps.

## How to use it

1. Pick one project or one training phase at a time.
2. Before starting, re-run the drone to see the *current* gap ranking:
   `generated/skills_demand.md` and `generated/**/missing_skills.md`.
3. When a project or course is actually built, move it out of this folder into
   its own repo and link it from the GeberLMS catalog.
