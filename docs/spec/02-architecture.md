# LMS Helveticore — Technical Architecture

Architecture / technical solution document. Number: SPEC-002. Version: 0.1.

## 1. High-level decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Runtime | Cloudflare Workers + Pages/Static Assets | Imposed deployment target; low cost, edge. |
| Framework | SvelteKit (adapter-cloudflare) | Full-stack, lightweight, SSR/SSG, excellent Workers support. |
| Language | TypeScript (strict) | Typing, testability, maintainability (NFR-05). |
| Database | Cloudflare D1 (SQLite) via Drizzle ORM | Lightweight, free at start, versioned schema. |
| Files | Cloudflare R2 | Learner uploads and resources. |
| Auth | Sessions on Workers + accounts in D1 | Full control, zero per-user cost. |
| Payment | Payoneer (Helveticore account validated) + Revolut withdrawal | Already validated for the operator; semi-manual flow compatible with admin-created accounts. |
| LLM | Workers AI (Gemini) by default, DeepSeek as an option | Abstraction layer to switch providers. |
| Tests | Vitest (business logic) | TDD, fast, no infra. |

## 2. Components

```
Browser ──► Cloudflare (SvelteKit SSR/edge)
                 │
                 ├─ D1 (users, courses, enrollments, coupons, invoices, logs)
                 ├─ R2 (videos, submitted documents)
                 ├─ KV (sessions, lightweight cache)
                 ├─ Payoneer (collection, withdrawal to Revolut)
                 └─ LLM (Workers AI / DeepSeek) — quiz generation
```

- **`src/lib/domain`**: pure business logic (price, VAT, coupons, progress). No framework/infra dependency → testable in isolation (TDD).
- **`src/lib/server`**: Cloudflare adapters (D1, R2, Payoneer, LLM) and API routes.
- **`src/routes`**: SvelteKit pages (learner, tutor, admin).

## 3. Data model (main entities)

- **User** — `id`, `role` (admin|learner|tutor), `self_payer`, `email`, `name`, `locale`, `status`.
- **Guardianship** — `tutor_id`, `learner_id` (tutor ↔ learner link).
- **Course** — `id`, `slug`, `title`, `language` (fr|en|ar|de), `status`.
- **Module** — `id`, `course_id`, `position`, `title`, `status`.
- **Lesson** — `id`, `module_id`, `position`, `title`, `type` (video|text|quiz), `content_ref`, `status`.
- **Resource** — `id`, `lesson_id`, `type`, `r2_key`, `visibility` (visible|hidden).
- **Enrollment** — `id`, `learner_id`, `course_id`, `payer_id`, `payment_ref`, `coupon_id`, `status`, amounts (`net`, `vat`, `total`).
- **Payment** — `id`, `stripe_ref`, `amount`, `currency`, `status`.
- **Coupon** — `id`, `code`, `type` (percent|amount), `value`, `scope`, `expires_at`, `max_uses`, `used_count`, `enabled`.
- **Progress** — `id`, `enrollment_id`, `lesson_id`, `status`, `score`, timestamps.
- **Attempt** — `id`, `quiz`, `answers`, `score`, timestamp.
- **Upload** — `id`, `learner_id`, `lesson_id`, `r2_key`, metadata.
- **Invoice** — `id`, `enrollment_id`, `number`, `pdf_ref`, amounts, `vat_rate`.
- **ActivityLog** — `id`, `actor_id`, `action`, `target`, `meta`, timestamp.

All amounts are in **integer cents** (BR-01).

## 4. Payment flow

1. The buyer (tutor or self-payer) chooses a course, optionally applies a coupon.
2. The LMS computes the price (discount + VAT at the buyer's country) via `domain/pricing`.
3. The admin issues a **Payoneer payment request** to the buyer (or Payoneer checkout if available); no card is entered in the LMS.
4. Payoneer notifies collection → the LMS (or the admin) activates the enrollment.
5. The admin creates the learner account via script/dashboard after payment.
6. The VAT invoice is generated by the system and archived.
7. Outside the LMS: funds are withdrawn from the Payoneer balance to the recovery Revolut account (see `PayoneerToRevolutHelveticore.png`).

> ⚠️ **To confirm**: the exact integration mode (semi-manual payment request vs automated Payoneer Checkout) and availability for an Estonian merchant must be validated. The semi-manual flow matches the "account created by admin after payment" model. Risk R-01.

## 5. Anti-copy strategy

Absolute anti-copy **does not exist on the web** (screenshot, photograph). The goal is to make *mass* extraction difficult:

- No PDF/EPUB export of the full course.
- On-the-fly, paginated content rendering (never a "whole course" page).
- Mixed content video + short text + interactive (less long flat text to copy).
- Disabling mass copy-paste on course areas (a deterrent, not security).
- Watermark on documents/videos.
- Access quotas and logging (FR-23) to detect abnormal behavior.

## 6. LLM strategy

- Abstraction layer `llm/generateQuiz(course, lesson)`.
- Default: **Workers AI (Gemini)** — stays within Cloudflare, unified billing.
- Option: **DeepSeek** via external API, same interface.
- Budget tracked: alert if monthly spend approaches €100 (NFR-06).
- Generated quizzes are **reviewed/validated by the admin** before publication (never auto-published).
- **LLM boundary:** course **authoring is 100% external** (Gemini/DeepSeek, manual writing) and injected via **JSON import** (milestone m3); the LMS calls no LLM to create/edit courses. Workers AI is reserved for the **runtime** (quiz variants), with an offline local mock and quotas.

## 7. Internationalization (i18n)

- Interface: French at launch, then EN / AR / DE (related NFR).
- Course content: monolingual (FR / EN / AR / DE) — one course = one language.
- RTL support planned for Arabic.

## 8. Decision register (ADR)

- **ADR-001** — SvelteKit rather than React: lightweight bundle, edge SSR, solo productivity.
- **ADR-002** — D1 rather than Postgres: free at start, sufficient for the target volume.
- **ADR-003** — Amounts in integer cents (no floats).
- **ADR-004** — Business logic isolated in `src/lib/domain` for TDD.
- **ADR-005** — Payoneer (already validated Helveticore, linked to Revolut) rather than Stripe, to avoid a new verification process.
- **ADR-006** — Pinning Vite 6 / vite-plugin-svelte 5 / vitest 3 (instead of bleeding-edge Vite 8) for stable, compatible dependency resolution.
- **ADR-007** — Coherent Cloudflare chain: adapter-cloudflare 7 + wrangler 4 + workers-types 5 (adapter 4.x was incompatible with wrangler 4).
